# VERA DICOM — PWA para Android

Prototipo de visor DICOM para tablet Samsung Galaxy Tab S10+.

**Estado: versión experimental, no validada para diagnóstico.** El prototipo usa Cornerstone3D y procesa DICOM locales en el navegador sin enviar archivos del paciente a un backend.

El código fuente y la configuración de despliegue estarán alojados en este repositorio. Para publicarlo en GitHub Pages se utiliza un flujo de GitHub Actions.

> No subir estudios DICOM, datos personales de pacientes ni credenciales al repositorio público.
